## 三、交互设计
- explain.html 四 Tab：① 项目提出 ② 项目分析 ③ 项目实施 ④ 展示交流与章小结。
  - 每 Tab 末尾「想一想」问题卡，不附答案，链到实验区占位。
- 实验区候选（后续批次，3D 优先）：
  - 隔音房间模型 3D 拼装实验（three.js）：用鞋盒/包装盒搭建房间，选择不同隔音材料（海绵、泡沫、纸板、毛巾）贴附内壁，播放固定音频并显示分贝计读数。
  - 控制噪声三途径小游戏：将“消声器、隔音墙、耳罩”等图标拖入“防止噪声产生 / 阻断噪声传播 / 防止噪声进入耳朵”三栏。
  - 声音传播路径可视化：3D 房间内声波从闹钟发出，碰到不同材料发生吸收/反射/透射。
- 练习区：本节为项目式学习，无传统“练习与应用”题目，可设置“方案设计”开放题与“隔音性能计算”填空题。
