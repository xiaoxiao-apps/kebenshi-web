## 一、章节结构

### 第2节 生活中的透镜（页118-121）
知识块顺序：
1. 问题（118）：露珠似大自然创造的"透镜"；生活中间透明的设备各有什么特点 → 引入
2. 照相机（118）：镜头=一组透镜≈一个凸透镜；物远 → 胶片上成缩小、倒立的像；早期照相馆取景即倒立缩小像；现代相机用光学/电子技术转正
3. 想想做做（119）：双纸筒模型照相机——一筒嵌焦距 5~10 cm 凸透镜、一筒蒙半透明薄膜；暗室内对明亮室外，拉动纸筒改变透镜-薄膜距离（=调像距）对焦；观察薄膜上的像是否倒立
4. 演示·观察投影仪成像（119）：取下平面镜（反光镜），投影片放载物台，调镜头，天花板上得清晰像；观察像的大小、正倒
5. 投影仪（120）：镜头=凸透镜；物近 → 成放大、倒立的像（投天花板）；会议室/教室投影仪原理类似
6. 放大镜（120）：凸透镜；置于物体与眼睛之间，适当调距离 → 看到放大、正立的像
7. 实像和虚像（120-121）：实像=光实际会聚而成、光屏能承接、物像位于透镜两侧（图5.2-7）；虚像=光不实际会聚、人眼逆出射光方向看去感到光从虚像位置发出、物像同侧（图5.2-8）；平面镜成虚像、放大镜也成虚像
8. 练习与应用（121）：5 题

### 第3节 凸透镜成像的规律（页122-125）
知识块顺序：
1. 问题（122）：照相机（物远→缩小实像）、投影仪（物近→放大实像）、放大镜（物距比焦距近→放大正立虚像）→ 像的虚实、大小、正倒跟物距有关系；有怎样的关系？
2. 实验·探究凸透镜成像的规律（122-124）：
   - 实验思路（122）：物体从较远处逐渐移近凸透镜，逐次记录物距与像的虚实/大小/正倒，比较数据找规律（图5.3-1）
   - 实验过程（123）：发光二极管作物、白色硬纸板作光屏；调节发光物体/凸透镜/光屏**中心高度相同**；物从远处逐次移近，每次移动光屏使屏上呈清晰实像，观察像的大小正倒、测物距像距；屏上接不到像时**撤去光屏，从光屏一侧向凸透镜方向看去**观察虚像及位置；记录数据并与各组共享
   - 记录表表头：物距/cm｜像的性质（虚实、大小、正倒）｜像距/cm
   - 实验结论引导（124）：三问——什么条件成实像/虚像？什么条件成放大实像/缩小实像？有没有缩小的虚像？什么条件倒立/正立？**建议以焦距 f 作参照距离**描述物距像距关系
   - 蓝框结论（124）：u>2f 成倒立缩小实像；f<u<2f 成倒立放大实像；u<f 成正立放大虚像
3. 想想议议（124）：照相机像的位置范围？物距与像距谁大？投影仪像的位置范围？成虚像时物距与像距谁大？
4. 练习与应用（124-125）：7 题（题5 为完整数据表分析题，f=10 cm）

## 三、数字与事实清单（逐字摘录）
- 术语与结论原句：
  - 「照相机的镜头由一组透镜组成，它们组合在一起相当于一个凸透镜」
  - 「照相时，物体离照相机镜头比较远，像是缩小、倒立的」
  - 「物体离投影仪镜头比较近，像是放大、倒立的」
  - 「把放大镜放在物体跟眼睛之间，适当调整距离……这时我们看到的像是放大、正立的」
  - 「如果把光屏放在像的位置，就能够承接到所成的像。这种像叫作实像」「它和物体分别位于凸透镜的两侧」
  - 「人眼逆着出射光的方向看去，感到光是从虚像的位置发出的。物体和虚像位于凸透镜的同侧」
  - 「像的虚实、大小、正倒跟物体到凸透镜的距离（物距）有关系」
  - 蓝框结论原句：「当物距大于2倍焦距时，凸透镜成倒立、缩小的实像；当物距小于2倍焦距、大于焦距时，凸透镜成倒立、放大的实像；当物距小于焦距时，凸透镜成正立、放大的虚像。这就是凸透镜成像的规律。」
  - 实验操作要点原句：「调节发光物体、凸透镜和光屏，使它们的中心高度相同」「当在光屏上看不到发光物体的像时，可以撤去光屏，从光屏一侧向凸透镜方向看去，观察发光物体的像」
  - 想想议议隐含事实：照相机 f<v<2f 且 u>v；投影仪 v>2f 且 u<v；成虚像时 |v|>u
- 数字与单位：
  - 想想做做模型照相机凸透镜焦距 **5~10 cm**
  - 练习5 数据表：发光物体高 **3.0 cm**；物距从 **4.0 cm** 起每次增加 **2.0 cm** 至 28.0 cm；表格隐含 **f=10 cm**（u<10 正立虚像屏接不到像距为空、u=10 不成像、u>10 倒立实像且 1/u+1/v≈1/10；u=20=2f 时像高 3.0=物高 等大）
- 符号：u（物距）、v（像距）、f（焦距）、F（焦点）、O（光心）、2F（二倍焦距点）
- 英文对照：本节无新英文术语（lens/convex lens/focus/focal length 已于 5.1 给出）
- ⚠️ 转录存疑处（不影响知识点）：页118 引言句、页120-121 衔接句、练习6/7 个别字句照片不清；练习6 两判断为「屏上出现手指的影/像或像残缺」vs「像仍完整但变暗」。
