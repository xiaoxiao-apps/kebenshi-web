## 物理正确性核对

- 水瓶琴：水越多 → 整体质量越大 → 振动越慢 → 音调越低。最左侧瓶水最多，发 do；最右侧水最少，发 i。
- 活塞哨子：空气柱越短 → 振动越快 → 音调越高。活塞越向下，频率越高。
