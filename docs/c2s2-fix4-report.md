# c2s2-fix4 修复报告（响度/音色实验）

**日期**：2026-09-18  
**范围**：仅修改 `content/physics_g8_v1_c2_s2/exp-loudness.{html,js}` 与 `exp-timbre.{html,js}`。

## 修复项

### exp-loudness 响度与振幅
1. **预加载消除首播延迟**  
   页面加载即创建 `hardAudio` / `lightAudio` 两个 `Audio` 对象，设置 `preload='auto'` 并调用 `load()`；点击时直接 `currentTime=0; play()`，无需重新设置 `src`。
2. **左右分栏 + 卡通人物**  
   - 左侧保留音叉与乒乓球弹开动画（轻敲/重敲幅度逻辑不变）。  
   - 右侧新增 SVG 简笔小人；拖动「距离」滑块时，人物按距离缩放并降低透明度（1 m → 10 m：scale 1 → 0.35，opacity 1 → 0.55），直观展示近大远小。  
   - 音量 gain 仍按 `1.1 / dist^0.7` 衰减。

### exp-timbre 音色对比
3. **满宽波形**  
   修复 `drawBand`：由按像素采样改为按数据点数均匀映射到整宽，三条波形均从左到右完整绘制。
4. **峰值归一化**  
   新增 `normalizeWave()`，对 Analyser 时域数据按各音源自身峰值归一化后再绘制，钢琴/长笛波形视觉振幅与音叉同量级；画布右上角增加说明「波形高度已归一化，便于对比形状差异」。盲辨游戏逻辑未改动。

## 验证
- `node --check` 两个 JS 文件通过。
- 浏览器自查：桌面与 iPhone SE 双尺寸布局正常；网络面板确认响度两音频在页面加载时即发起 `206` 预加载请求；人物随距离滑块联动（验证 transform/opacity 输出）；音色页波形提示文案显示正常、线条满宽。
