## 蔡总第十轮：初始灯灭+点火才计时（s15）

蔡总原话：「初始化的状态应该是，酒精灯应该是熄灭的状态。虽然默认是开始的状态。但是温度时间曲线并不会走动，时间也不会计时，当我点击点燃酒精灯之后，时间才开始计时曲线图也才开始往前走，然后再点击熄灭酒精灯之后时间继续往前走，并且曲线图也往前走，一直到我点击重置时间和曲线图才能停下来。」

改法：
1. `makeInitialState` 默认 `heating: false`（灯灭）、`paused: false`（运行态不变）；
2. 计时门控前移到 `stepPhysics` 开头：`firstHeatT == null`（从未点火）时直接 return——simTime 不走、曲线不画、温度不变；`firstHeatT` 只在点火那刻设置，熄灯不清除→时间/曲线继续；只有 `clearTable()`（重置/初始 simTime=0 时改环境温度）才清 `firstHeatT` 归零；
3. `recordData` 里的门控同步简化（计时锁已前置）；
4. init/resetAll 的灯钮文案改为「点燃酒精灯」+primary 样式；
5. 顺手修：环境温度滑杆 simTime=0 时改用 `clearTable()`（原来只清表不清曲线）。

实测（浏览器 s15 全链路，errors=0）：
- 初始：heating=false、paused=false、simTime=0、chartPts=0、灯钮「点燃酒精灯」；灯灭空跑 12s 时间曲线纹丝不动；
- 点火后：simTime 走到 15min、曲线 31 点、T=100℃、钮变「熄灭酒精灯」；
- 熄灯后：时间继续 15→24min、曲线 31→49 点、温度自然下降 70.3℃（时间和曲线都不停）；
- 重置后：simTime=0、曲线 0 点、表 0 行、灯钮回「点燃酒精灯」，再空跑依旧冻结（回到初始态）。
- node 冒烟同步全绿（灯灭冻结/点火走/熄灯不停）。

## 蔡总第六轮：沸前气泡只在下半部分（s9）

**问题**（附截图）：沸前气泡集中在水柱下半，到 100℃ 突然变成全柱上升，过渡突兀。
**根因**：`top = WATER_H*(0.35+0.25*seed)` 把沸前气泡上升上限写死在 35%~60% 水柱高；初始 y 分布也只铺底部 40%；life 衰减过快气泡活不到高处。
**改法**：top 改为 `WATER_H*(0.92+0.08*seed)`（全水柱）；初始 y 铺满 95% 水柱；life 衰减降为 `dt*(0.15+0.2*seed)*(0.3+collapse)`——低温时气泡上升途中收缩消失（响水不开），越接近沸点消失越少、直达水面，与沸腾态自然衔接。
**实测**（浏览器 s9 读实例位置，errors=0）：沸前各温度气泡分布 y=0.4→5.7（水柱 5.8）全覆盖；上半水柱气泡数随温递增 3→11→19；沸腾态 y=0.25→5.76 无跳变。

## 蔡总第五轮：气泡大小变化不明显（s8）

**问题**：s7 的 szBase 幅度太弱（0.35→1.10，3 倍且峰在 97℃），渲染层再乘收缩系数后视觉上几乎看不出变化。

**改法**：新建 `preboilBubbleSize(T)` 纯函数（physics.js，可 node 冒烟）：
- 50~55℃：0.15→0.25（零星极小泡）
- 55→80℃：0.25→**1.80**（线性变大，峰值 80℃，峰谷 7.2 倍）
- 80→98℃：1.80→0.40（明显变小，峰后缩 4.5 倍）
- 渲染层：上升收缩系数、气泡存活率都随温度联动（越接近沸点收缩越少）；沸腾后 boilBubbles 上升变大系数从 0.8 提到 1.8（教材原句「上升、变大」更明显）。
- 85℃ 弹窗文案同步修正：「气泡变大」→「气泡逐渐变小、破裂减少」（与阶段 3 尺寸走向一致）。

**实测**（浏览器 s8 读实例矩阵真实缩放，errors=0）：55℃=0.22 → 70℃=1.01 → **80℃=1.60（峰）** → 90℃=0.97 → 97℃=0.46 → 沸腾切换 boilBubbles（上升变大）。小→大→小全程 7 倍幅度，肉眼可辨。
