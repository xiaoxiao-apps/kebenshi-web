## 四、实验清单

### 4.1 实验：探究水在沸腾前后温度变化的特点（P71~P72）

- **实验思路**：与上一节的固体熔化实验类似；将水加热至沸腾，测量水的温度，根据记录的数据绘制图像，得出水在沸腾前后温度变化的特点。
- **器材**：酒精灯（或家庭常用的电水壶、电热水壶等）、烧杯、铁架台、纸板（配温度计）、实验室用温度计、秒表（计时）。
- **步骤**：
  1. 如图3.3-2所示，用酒精灯（或电水壶、电热水壶等）将水加热，使其沸腾。
  2. 用实验室用温度计测量水温；当水温接近90 ℃时开始计时。
  3. 每隔0.5 min读数一次并将温度填入表中，直到水沸腾4~5 min后为止。
- **数据表**：

  | 时间/min | 0 | 0.5 | 1 | 1.5 | 2 | 2.5 | 3 | … |
  |---|---|---|---|---|---|---|---|---|
  | 温度/℃ |   |   |   |   |   |   |   |   |

- **图像**：图3.3-3 水沸腾前后温度变化的图像（空白坐标图，纵轴温度/℃刻度90、95、100、105，横轴时间/min，带网格，供描点绘制）。
- **结论**：水在沸腾前，温度不断升高；水在沸腾后，温度保持不变。沸腾时大量气泡不断上升、变大，到水面破裂开来，水蒸气散发到空气中；沸腾过程中虽温度保持不变，但要用酒精灯持续加热，故不断吸热。
- **（教材原句填空）**：根据实验数据的整理和分析，总结水在沸腾前后温度变化的特点：＿＿＿＿＿。

### 4.2 想想做做：纸锅烧水（P73）

- **背景**：着火点是物质可以燃烧的最低温度；纸的着火点大约是183 ℃，当纸的温度达到183 ℃时它会燃烧起来，而火焰温度通常比纸的着火点高得多。
- **器材**：一张光滑的厚纸。
- **步骤**：照图3.3-4把厚纸做成小纸锅；纸锅里装些水，放到火上加热；注意不要让火苗烧到水面以上的纸。
- **现象/结论**：过一会儿水就会沸腾，而小纸锅不会燃烧。
- **追问**：实际做一做，说一说小纸锅为什么不会燃烧。

### 4.3 想想做做：蒸发吸热（P73）

- **器材**：医用酒精棉球（或湿巾）、实验室用温度计、扇子。
- **步骤/问题**：
  1. 把酒精擦在手背上，手背有什么感觉？这可能是什么原因引起的？
  2. 把酒精反复涂在温度计的玻璃泡上，用扇子扇，温度计的示数有什么变化？
  3. 如果温度计上不涂酒精，用扇子扇，温度计的示数会变化吗？
- **现象/结论（P74）**：酒精蒸发过程中吸热，使人感到擦酒精的位置发凉，致使酒精及与酒精接触的物体温度下降。

### 4.4 液化（P74，陈述式，无独立动手操作）

- 证明气体可液化的两条途径：① 所有气体在温度降到足够低时都可以液化；② 在一定的温度下，压缩气体的体积也可以使气体液化。
- 生活实例：北方冬天呼出"白气"、戴眼镜者从寒冷室外进入温暖室内镜片蒙上水珠、草叶昆虫上的露珠、常温下压缩体积使石油气液化装瓶、火箭中氢和氧以液态贮存。
- 放热：液体汽化吸热，气体液化放热；水蒸气液化时放出大量热，故水蒸气烫伤往往比开水烫伤更严重。

### 4.5 STS：青藏高原上的"冰箱"（P75）

- **电冰箱原理**：制冷剂采用既容易汽化又容易液化的物质；液态制冷剂经毛细管进入冷冻室管子，汽化、吸热使箱内降温；蒸气被压缩机压入冷凝器，液化并放热。
- **热棒（热管）**：封闭中空长棒，一般填充低沸点的液态氨；下端插冻土，液态氨吸热汽化成气态氨，寒冷季节气态氨升到上端经散热片放热变回液态氨沉回棒底，循环把冻土中的热散发出，冻土不易融化，减小路基影响。
