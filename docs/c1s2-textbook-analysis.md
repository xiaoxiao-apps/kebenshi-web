## 二、教材内容要素盘点

### 2.1 黑体定义/结论（3处）
1. **机械运动**（mechanical motion）：物体位置随时间的变化。（第17页，唯一带英文的黑体词）
2. **参照物**：判断运动和静止时作为标准的物体。（第18页）
3. **物体的运动和静止是相对的**。（第18页末，收割机例后）

### 2.2 插图（图1.2-1 ~ 1.2-5，共5幅）

| 图号 | 内容 | 教学功能 |
|---|---|---|
| 图1.2-1 | 蜗牛在叶上缓慢爬行（照片，带阴影） | "问题"栏目配图，引出"根据什么判断物体运动" |
| 图1.2-2 | 地壳运动使珠峰高度变化（雪山照片） | 机械运动的非常见实例（缓慢、宏观） |
| 图1.2-3 | 运水稻车辆与联合收割机同速同向前进（稻田照片） | 相对静止核心例证："以任何一个为参照物，另一个静止" |
| 图1.2-4 | 甲：人乘自动扶梯；乙：加油机对受油机空中加油（3机） | 想想议议②配图，参照物选择双向判断 |
| 图1.2-5 | 梦天实验舱与天和核心舱对接（太空场景，舱段标注） | 练习③配图，落实课标活动建议(3)的航天情境 |

### 2.3 栏目结构

| 栏目 | 数量/位置 | 内容摘要 |
|---|---|---|
| ❓问题 | 1处，第17页开篇 | 彗星/猎豹/蜗牛三种运动，"根据什么判断物体是运动的？" |
| 想想议议 | 2处 | ①第18页：并排列车错觉（自以为前进，实为旁车后退）；②第19页：图1.2-4甲扶梯人与乙受油机，选什么参照物运动/静止 |
| 练习与应用 | 1处4题，第19页 | ①列车行李架物品 vs 火车头/座椅/树木/房屋；②《社戏》"山向船尾跑去"参照物；③空间站对接前/后/以地面指挥中心为参照物三问；④观光电梯判断上行下行的依据 |
| 无 | — | 本节无"科学世界""STS""动手动脑学物理"，无侧边栏小字、无脚注（转录已复核确认） |

### 2.4 正文知识骨架
- 第17页：问题导入 → 一、机械运动（定义+实例+运动普遍性/形式多样+本章定位）
- 第18页：二、参照物（"事情真这么简单吗"反问 → 想想议议列车错觉 → 参照物定义 → 列车例双参照物分析 → 参照物可按需选择：地面vs太阳看房屋 → 收割机相对静止 → 黑体结论）
- 第19页：想想议议②（扶梯/加油机）→ 练习与应用4题
- 隐含判断方法（教材未黑体但需提炼）：**选参照物 → 看被研究物体与参照物间位置是否变化 → 变化则运动，不变则静止**

## 三、c1s2 模块与互动设计方案

### 3.0 页面结构（完全沿用 c1s1 骨架）
```
content/physics_g8_v1_c1_s2/
├─ index.html        本节导航（nav-grid 3卡：知识讲解/互动实验区/小练习）
├─ explain.html      知识讲解（"好学生课堂笔记"风）
├─ experiment.html   互动实验区入口（nav-grid 4卡 → 4个exp页）
├─ quiz.html         练习与应用（教材4题为主，含对接联动工具）
├─ exp-motion.html / exp-reference.html / exp-train.html / exp-harvester.html
├─ common.css（复制c1s1后仅追加局部提亮变量）、exp-common.js、fullscreen.js、exp-back.js
```
导航纪律：只留顶部 `back-btn`（‹ 返回）+ 卡片网格，不做侧栏/底tab/面包屑堆叠。
CSS 纪律：只用 common.css `:root` 白名单变量（--bg/--card/--card2/--ink*/--brown*/--green*/--red*/--cyan/--cyan-bg/--gold/--r/--shadow*），**无 --primary 不要发明**。语义色提饱和一档的做法：exp 页局部 `<style>` 里加 `--cyan-hi: #3fa7e8; --green-hi: #5cb84e;`（c1s2 自己的 common.css 副本可收编），底色维持暖纸 #faf8f5，禁止冷蓝底。

### 3.1 exp-motion.html「位置在变吗——什么是机械运动」
- **对应教材**："问题"栏目 + 图1.2-1（蜗牛）/图1.2-2（珠峰）；课标教学提示①（实例→概括共同特征）。
- **教学目的**：经历概念建构过程：看彗星/猎豹/蜗牛三个快慢悬殊的实例，自己概括出"位置随时间变化"，再揭示机械运动定义。
- **交互机制**：
  - 控件：单主按钮（状态机）+ 时间轴 slider + 轨迹开关。
  - 状态机（按钮文字即进度）：`▶ 观察彗星` → `▶ 观察猎豹` → `▶ 观察蜗牛` → `🤔 它们的共同点？`（学生点选：颜色/位置变化/速度快 → 选"位置变化"才过关）→ `📖 看定义` → `⟲ 重新观察`。每步 canvas 动画 3-5s，物体带拖尾轨迹点（间隔相等时间打点，暗示"位置随时间变化"）。
  - slider scrub：任一实例播完后，slider 变为该实例的时间轴，拖动回看任意时刻物体位置，轨迹点同步高亮当前点（借竞品"面动成体"scrub 思路）。
  - 反馈形式：无弹窗；结论以卡片从下方滑入（250ms ease），错误点选抖动+变红（--red）后自动复位。
- **防剧透**：定义卡片在概括环节完成前隐藏；首屏提示条："点下方按钮，依次观察三种运动，找出它们的共同点"。

### 3.2 exp-reference.html「点谁谁是标准——参照物选择」
- **对应教材**：第18页正文（房屋/桥梁/树木 vs 地面/太阳）+ 判断三步法；想想议议②的扶梯场景。
- **教学目的**：建立"参照物可按需选择；参照物不同结论一般不同"；练熟"选标准→比位置→下结论"。
- **交互机制**：
  - 控件：一幅可点击的街景 SVG/canvas（行驶的汽车、路旁树木、房屋、行人、天上的太阳）+ 目标物体切换 pill（汽车/树木/行人）+ 结论显示区。**点击场景物体本身即设其为参照物**（直接操纵隐喻，竞品工具4"点棱剪开"式），被选参照物描金色脉冲环（--gold），目标物体描青色环（--cyan-hi），两环颜色全程不变帮追踪。
  - 状态：无多步流程，纯自由探索 + 轻任务链（"任务：让汽车显示为静止"→学生点车内座椅/司机即达成 → 任务2："让树木动起来"→点太阳或汽车）。首次进入时参照物候选有脉冲描边指引。
  - 反馈：选定后立即显示结论条："以【太阳】为参照物，【房屋】的位置在变化 → 运动"（关键词内嵌 --red/--gold 高亮），250ms 渐变切换不硬切。
- **防剧透**：任务目标完成前不给答案文案；结论条只在做出选择后出现。

### 3.3 exp-train.html「列车错觉——想想议议①」
- **对应教材**：第18页想想议议①（并排列车错觉）。
- **教学目的**：解释错觉成因：以旁车为参照物→误判自己运动；以站台为参照物→真相静止。
- **交互机制**：
  - 控件：单主按钮状态机 + 参照物切换 pill（站台/旁边列车）+ 视角窗。
  - 状态机（分步播放，按钮文字即进度）：`▶ 坐在车厢里`（第一人称车窗视角，旁车并排静止）→ `继续：好像动了？`（旁车缓慢"后退"，车窗内画面平移，产生"我车前进"错觉）→ `继续：驶过车尾`（旁车车尾掠过+站台立柱入画——真相：是旁车在开走）→ `🔍 切换参照物验证`（进入自由态：pill 选站台→"你乘坐的列车：静止"；选旁车→"运动"）→ `📖 结论` → `⟲ 再体验一次`。
  - 反馈：结论卡片滑入；错觉阶段屏幕边缘轻微视差移动增强沉浸；无音效依赖。
  - 过渡：每步切换 250ms 淡入淡出，禁止零动画硬切（竞品坑1）。
- **防剧透**：真相步骤前不出现"旁车在动"字样；首屏提示条："你坐在停站的列车里，先体验一个错觉，再找原因"。

### 3.4 exp-harvester.html「收割机与运稻车——相对静止 + 时间轴」
- **对应教材**：图1.2-3 + 黑体结论"物体的运动和静止是相对的"。
- **教学目的**：理解"同快慢、同方向→互为参照物静止"；用时间轴回看任意时刻两车位置关系，建立相对位置不变=相对静止的直观。
- **交互机制**：
  - 控件：播放/暂停主按钮 + **时间轴 slider（核心）** + 参照物三选 pill（地面/收割机/运稻车）。
  - 场景：金黄稻田横向卷轴（--gold 系暖色），收割机与运稻车同速右行；选"地面"参照物→两车都动、背景滚动；选"收割机"→画面锁定收割机居中，运稻车与它保持相对位置纹丝不动，背景滚动（视觉上"运稻车静止"）。
  - slider scrub：拖到任意时刻 t，两车跳到该时刻位置；开启"位置印记"后每隔1s在两车下方打点，切换参照物时印记点跟随坐标系变换——学生自己发现：以地面看点在移动，以收割机看运稻车的点原地重叠（相对位置不变）。
  - 状态机简化为：`▶ 出发` → `⏸/▶` → `⟲ 重置`；pill 切换带 250ms 视角平滑移动过渡（相机插值，不瞬移）。
  - 反馈：结论条实时联动 pill（选哪个参照物立刻改文案+动/静徽章，绿=静止 --green-hi，红=运动 --red）。

### 3.5 explain.html 内容大纲（"好学生课堂笔记"风，干练无铺垫）
1. **两个黑体定义卡**：机械运动（物体位置随时间的变化，英文 mechanical motion）；参照物（作为标准的物体）。
2. **判断三步法**（steps 有序卡，沿用 c1s1 .steps 样式）：①选定参照物 → ②看目标与参照物间位置是否变化 → ③变了=运动，没变=静止。
3. **三个必背要点**（tipbox）：参照物可按需选择、假定其不动；参照物不同结论一般不同；运动和静止是相对的（收割机例一句话带过，链到 exp-harvester）。
4. **易错点**：不能选被研究物体自身为参照物（无意义）；"太阳东升西落"参照物是地面/观察者；诗句题找"谁在动、相对谁"（链 quiz②）。
5. 内嵌 2 个 mini 联动（沿用 .mini-quiz 样式）：a. 扶梯人（图1.2-4甲）参照物下拉→动/静徽章实时变；b. 一句话概括列车错觉成因填空（默认遮盖，点击揭晓——防剧透）。
6. 不做"引入铺垫"段落；每屏一个主题，同类内容 Tab 单显（如易错点用 tab 切"概念/诗句/航天"三类，不堆一页）。

### 3.6 quiz.html 设计（练习优先实时联动，不做"题+检查按钮"堆砌）
- 题1（行李架物品）：四参照物 pill 逐个点→物品"静止/运动"徽章实时翻转，全对后自动亮"完成"。
- 题2（《社戏》连山）：输入/选择参照物→点"揭晓"前显示"船在前进中…"情境动画提示，答案默认遮盖。
- 题3（空间站对接，图1.2-5 / 课标活动建议3）：**做成联动小工具**——slider 播放梦天靠近→对接→转位成"T"字构型的简化动画；三个问题（对接前以天和为参照/对接后以天和/以地面指挥中心）以 pill 组呈现，拖动 slider 时结论徽章实时更新。放 quiz 页内嵌，不单独开 exp 页（宁精勿滥，机制与 exp-harvester 同族）。
- 题4（观光电梯）：简答自评卡：给"看窗外建筑物与电梯的相对位置变化"参考答（点击揭晓）+ 自评"我明白了"。
- 另补 2~3 道基础选择（机械运动定义辨析）凑 6~7 题，沿用 c1s1 quiz 判分与反馈样式。
