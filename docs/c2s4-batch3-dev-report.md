## 5 题覆盖与判分方式

1. **第①题（开放题·调查）**：调查校园/家周围噪声+控制措施。reveal-btn「示例要点」含具体噪声源举例及对应三途径措施；附自查两要素。
2. **第②题（开放题·实践测量）**：安静环境测 1 min 脉搏 vs 声音过大环境再测。reveal-btn「示例要点」说明噪声环境下脉搏通常加快，反映噪声影响生理；附自查两要素。
3. **第③题（match-row 判断判分）**：教室免受噪声干扰 4 法判断有效/合理。每行两按钮（有效合理/无效或不合理），选错即时标 wrong 并亮出正确项，4 行全答后 feedback 计分，理由用 `<details>` 展开。
   - （1）老师讲话声音大一些 → 无效或不合理（增大声源噪声）
   - （2）每位学生戴防噪声耳罩 → 无效或不合理（能隔声但影响听课）
   - （3）教室周围植树 → 有效合理（阻断传播）
   - （4）安装噪声监测装置 → 无效或不合理（只监测不减弱）
4. **第④题（开放题·感受）**：说噪声感受+找来源。reveal-btn「示例要点」给出感受与来源示例；附自查两要素。
5. **第⑤题（简答题）**：高架桥隔音板道理。reveal-btn「示例要点」给出参考答案要点：隔音板在传播过程中阻断/吸收噪声，减弱传入住宅区；附自查两要素（途径归属+效果）。
