# c1s4 瑕疵修复清单（第6步用）

## F1. exp-slope 动画几乎匀速，分段速度无差异【教学硬伤，必修】
- 现象：自动计时测得 t2≈t1/2 → v1≈v2≈v3（55.25/54.95/55.56），小车"没有越滑越快"
- 教学要求：小车从静止加速下滑，应明显呈现 v上半段 < v全程 < v下半段（理想匀加速 t2≈0.71·t1）
- 修法：动画位移曲线改为 t² 匀加速（或分段关键帧），且秒表计时与位移曲线严格同步；坡度3档对应3组加速度档位，都要满足 t2 明显大于 t1/2
- 验收：默认档位下 v3/v2 ≥ 1.4

## F2. （观察项）手动模式重复测量表只记全程，不记上/下半段
- B2报告明示的已知限制，若修复成本低则顺带做；高则保留现状（报告已声明）
