## 四、实验/演示清单

### 4.1 碘的升华和凝华（P77，问题栏目，课堂演示）

- **器材**：带盖密闭玻璃容器、少量碘颗粒、热水、冷水。
- **操作**：先向容器浇热水（图3.4-1左），再浇冷水（图3.4-1右）。
- **现象**：浇热水 → 固态碘受热，容器内充满紫色碘蒸气（升华为气态）；浇冷水 → 碘蒸气遇冷变回固态碘（凝华）。
- **价值**：本节主演示，直接建立「升华/凝华」定义，与3.1「汽化/液化」互相对照（直接固态⇌气态，不经过液态）。

### 4.2 干冰（P78，陈述）

- 固态二氧化碳（干冰）在常温下升华吸热，用于食品运输降温、人工降雨、舞台“白雾”。非现场动手演示，属知识点陈述+照片/动画可表现。

### 4.3 易拉罐制霜演示（P80，练习与应用第4题，含图3.4-6/7）

- **器材**：易拉罐、冰块、盐、筷子、温度计。
- **操作**：冰块放入易拉罐并加盐，筷子搅拌大约半分钟，温度计测量冰盐水混合物温度。
- **现象**：混合物温度低于 0 ℃（F7），易拉罐下部/底部外壁出现白霜（图3.4-7）。
- **原理**：盐使冰的熔点降低，混合物温度低于0℃；罐外壁周围空气中的水蒸气遇冷→凝华成霜。

### 4.4 想想议议：水的三态联系（P78，图3.4-3，填空）

- 补全水蒸气/水/冰三者之间的演化方向并标注吸热/放热。属知识点梳理，非动手实验。

### 4.5 水循环（P78，图3.4-4，陈述 + 示意图）

- 蒸发（吸热）→ 液化（小水滴成云）→ 降水（雨/冰雹/雪）→ 径流（小溪/清泉/江河）→ 归大海。物态变化链，可做动画。
