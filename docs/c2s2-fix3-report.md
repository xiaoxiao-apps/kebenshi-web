## 修复项

1. **示波器波形满宽**
   - canvas 绘制由 `i * step` 改为按采样点比例映射到 `x = i/(len-1)*W`，波形从左到右完整覆盖。

2. **示波器交互改为滑块+播放/停止**
   - 删除 220/440/880 按钮，加入 100~1000 Hz 连续滑块。
   - 按 slider 值就近切到 `fork-220.m4a` / `fork-a4-440.m4a` / `fork-880.m4a`，并用 `playbackRate` 微调对齐当前 Hz。
   - 拖动中若播放，实时变调、波形疏密同步变化。
   - 侧边读数「1 s 内振动 ___ 次 = ___ Hz」随 slider 实时更新。
   - 保留「先预测后揭晓」。

3. **听觉范围纯音改为持续模式**
   - 点播放后 WebAudio oscillator 持续循环；拖动 slider 音高实时跟随。
   - 进入 >20 000 Hz 或 <20 Hz 区域时显示「超出人耳听觉范围，听不到」，并将增益归零。
   - 加入「停止」按钮。

4. **对数轴刻度重叠**
   - 仅标注 10 的幂次（1,10,100,1 000,10 000,100 000），200 000 保留刻度线但不再标数字。
   - 「次声波」「超声波」文字上移，桌面与 390px 均不重叠。
