## 二、第4节实验规划（2 个实验，待拍板）

### 实验①《升华凝华探究馆》（主实验，整合）

**核心场景（只搭一个）**：3D 密闭玻璃容器内装少量固态碘颗粒（图3.4-1复原），容器下方一个可切换的加热盘/冷。学生点击「浇热水」或「浇冷水」，容器内状态实时切换。

**器材复用来源**：
- 密闭玻璃容器 → 复用 `器材制作库·烧杯`（c3s2 `buildBeaker`），加透明杯盖（玻璃随动件），得密闭容器。
- 固态碘颗粒 → 复用 `器材制作库·试管` 中「固态样品粒子」InstancedMesh 做法（c3s2），改颜色为深紫黑色 `0x3a2340`。
- 紫色碘蒸气 → 半透明气体粒子/网格（同「沸腾气泡」/样品粒子思路），升腾动画。
- 实验桌 → 复用 `器材制作库·实验桌`（c3s2 `buildTable`）。
- 酒精灯火焰条目仅备查；**教材明确「不用酒精灯直接加热」（题1，因碘焰点低于火焰温度会熔化），故本演示用热水/冷水浇，不用火焰**。

**四个模式与知识点覆盖表**：

| 模式 | 内容 | 覆盖知识点 |
|---|---|---|
| ① 碘的升华凝华（主模式） | 浇热水→固态碘受热，容器内充满紫色碘蒸气（升华）；浇冷水→碘蒸气遇冷变回固态碘（凝华）。定义弹出「升华/凝华」双语（sublimation/deposition）。直接固态⇌气态，不经过液态，与3.1汽化液化对照 | 升华定义、凝华定义、直接固⇌气互变 |
| ② 生活现象馆 | 卡片/图例切换：樟脑片渐小至不见（升华）、结冰湿衣慢慢变干（升华）；窗玻璃冰花、霜、雾凇生成动画（凝华） | 升华生活实例、凝华生活实例（霜/冰花/雾凇） |
| ③ 吸放热 + 干冰 | 热流箭头方向对比（升华吸热↔凝华放热）；干冰演示：食品盒降温/人工降雨/舞台白雾三段动画 | 升华吸热、凝华放热、干冰应用（制冷/人工降雨/白雾） |
| ④ 易拉罐制霜（可选演示，源自练习第4题） | 冰块+盐入易拉罐搅拌→温度计示数跌破0℃→罐外壁结白霜（图3.4-6/7） | 冰盐降温、水蒸气遇冷凝华成霜 |

**参数面板**（联动全模式）：热水温度档、冷水档、碘颗粒量、干冰量。
**音效**（WebAudio 零外部文件）：浇热水滋啦、碘蒸气升腾呼啸、凝华轻滴、模式切换咔哒 + 静音钮。

### 实验②《水循环》（轻量动画实验，待拍板是否独立或并入小结）

**核心场景**：2D/轻量3D 水循环全景（图3.4-4），点击各环节看物态变化；含水的三态联系图3.4-3补全 + STS水资源数据可视化。

**三块内容**：
1. 水的三态联系（图3.4-3）：拖动补全水蒸气/水/冰之间的箭头方向 + 吸热/放热标注（不出题，现象自说）。
2. 水循环链条（图3.4-4）：蒸发（吸热）→ 小水滴成云（液化）→ 降水（雨/冰雹/雪）→ 径流（小溪/清泉/江河）→ 归大海，循环动画。
3. STS水资源（图3.4-5）：70%/97%/3%/0.3% 占比条可视化 + 节水场景。

**归属说明**：本块为文字性/数据性+动态链条，动画价值中。可并入「本章小结」（开发方案：纯记忆性不硬凑）。是否独立成第2个实验**待蔡总拍板**（推荐：独立成轻量实验，因水循环是本章串联所有物态变化的收口题，动画价值高）。

## 四、跨学科实践第5节——处置选项（2~3 个，待蔡总拍板）

> 依据开发方案：跨学科实践为项目式，非传统实验，不硬凑实验。以下三选项，标注利弊，**不擅自决定**。

### 选项 A：做「项目引导页」（轻量，推荐）

- **内容**：第5节一张引导页（非实验卡片），含项目提出（厨房=物态变化"实验室"）、项目分析三任务、观察表格（两行样例已填+两行留白）、警示框（安全提示）、展示交流形式。
- **利**：忠实教材"跨学科实践=课后项目"定位；开发成本最低；学生照页操作。
- **弊**：无可交互动画，违背"重点是可交互动画"的产品定位；交互价值低。

### 选项 B：做轻量交互（煮饺子互动卡片）

- **内容**：一张轻量交互卡片 = 煮饺子场景（图3.5-2）：水沸腾温度稳定100℃（汽化）+ 打开锅盖白雾（液化）+ 大火/小火切换展示"沸腾后大火不更快熟，改小火" + 水蒸气烫伤更严重对比。观察表格加填空交互。
- **利**：有交互价值，兑现"厨房=物态变化实验室"的动画辅助；知识点（沸腾100℃、汽化、液化、小火省燃料、水蒸气烫伤）落到动画。
- **弊**：中量开发成本（1个场景+多状态切换）；需新建厨房场景（无现成器材库条目）。
- **注意**：厨房场景无器材库现成条目，需新建煎锅/汤锅/饺子等模型，成本高于第4节复用。

### 选项 C：并入本章小结（零开发）

- **内容**：第5节内容作为「跨学科实践：厨房中的物态变化」整理 block 并入 c3_summary，不单独建节卡片页/页面。
- **利**：零开发，符合"文字性内容用小结带过"；不硬凑。
- **弊**：跨学科实践这一栏目在章内无独立落点，导航上第5节"空缺"；煮饺子等有动画价值的点未利用。

**待蔡总拍板**：三选一（或 A+B 组合：引导页 + 煮饺子轻量交互小卡）。
