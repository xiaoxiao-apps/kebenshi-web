## 改动
- exp-echo.html SVG：waveGo/waveBack 由同心圆扩圈改为**声波脉冲弧线组**（去程开口向右的三层弧、回程开口向左虚线弧），新增 cliffFlash 崖面撞击闪光矩形。
- exp-echo.js shout()/playWaveAnim() 重写：
  - 去程：弧线组从「你」(x=70) 平移至崖面 (x=540)，标签「📣 声波从你出发，向山崖传播…」；
  - 撞崖：崖面闪光 220ms，标签「💥 撞上山崖！声波被反射回来…」；
  - 回程：回程弧线组从崖面平移回「你」，回到耳边时标签收尾；
  - 音频对齐动画：喊声立即播，回声音频在**反射波回到耳边的动画时刻**响起（t>0.1s 回声减半音量；t≤0.1s 混响叠加）；rAF 驱动，连点可中断重播（clearAnim 清 rAF+timers）。
- 删文字：verdict 可分辨分支去掉「点『喊一嗓子』听——原声之后隔 x s 传来一声清晰的回声」，只留「✅ t = … s > 0.1 s：能分辨出回声。」
- hint 文案同步改为「喊声出发，反射声波回到耳边的瞬间播对应的回声/混响」。
