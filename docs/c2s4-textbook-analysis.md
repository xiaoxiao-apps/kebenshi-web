## 三、交互设计
- explain.html 四 Tab：① 噪声的来源 ② 噪声的危害 ③ 控制噪声 ④ 问题导入与图例总览。
  - 每 Tab 末尾「想一想」问题卡，不附答案，链到实验区占位。
- 实验区候选（后续批次）：
  - 噪声波形 vs 音叉波形示波器演示（2D Canvas 波形动画，教材示波器照片保真）。
  - 控制噪声三途径分类互动：将“消声器、隔音墙、耳罩”等图标拖入“防止噪声产生 / 阻断噪声传播 / 防止噪声进入耳朵”三栏。
