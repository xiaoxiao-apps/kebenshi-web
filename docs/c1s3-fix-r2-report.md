   全部改用 `vARun` → 新速度只在点播放时生效。

   `posA()` → 与滑块彻底解耦；乙车标尺维持教材值不变。
4. `t >= 40` 时在实际停止位置画终点标记：橙色竖线（#e67e22，hex）
   + "终点 NNN m" 文字（右对齐避让右上角时间戳；上限 W-6 防出界）。
