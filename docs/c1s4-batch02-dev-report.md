## 功能清单
1. SVG 场景：长木板、木块、刻度尺（0~100 cm）、金属片、小车；倾角随坡度变化。
2. 控制面板：坡度 3 档、自动/手动计时切换、金属片底端/中部、释放/再测一次/停止按钮、秒表读数。
3. 教材 5 步状态条，当前步骤高亮并显示操作提示。
4. 数据记录表：全程/上半段/下半段，填 s、t 自动算 v；下半段用 (s₁−s₂)/(t₁−t₂) 间接求得并高亮。
5. 自动计时：撞击后自动记录 0.01 s 精度时间。
6. 手动计时：学生自己按“停止”，系统加入 0.10~0.40 s 反应误差；多次测量表格追加并求平均。
7. 想想议议折叠区：方案 A/B 对比，解释“中部静止释放改变运动状态”导致速度偏小。
8. 页面顶部已声明动画为示意图，不声称物理精确。
