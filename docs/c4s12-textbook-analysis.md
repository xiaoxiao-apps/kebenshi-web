### 3.2 空格分节写法（原文保留）

- 精确光速用半角空格分节：`299 792 458 m/s`。
- 科学计数法不用空格：`3×10⁸ m/s`、`3×10⁵ km/s`。
- 分数用斜杠：`3/4 c`、`2/3 c`（c 前有空格）。
- 大数分节：`1 000亿`、`1.2万面`、`1 000`（存疑段）。
- 时间/速度：`8 min`、`500 km/h`、`2.56 s`。
- 角度：`30°`。

### 3.3 练习与应用判分推导值（供日后本章练习页判分）

#### 4.1 练习与应用（P92，5题）

**题1 手影**：判「光沿直线传播，手挡住光后在墙上形成影」。无数值，判关系不判数。

**题2 立竿见影**：判「竿挡住太阳光，光沿直线传播不能绕到竿后 → 竿后无光区即影」。同题1逻辑，判物理过程表述。

**题3 举例**：开放题，参考答案如激光准直、三点一线瞄准、影子/皮影戏/日食月食。无唯一标准。

**题4 日地距离估算**（唯一含计算，推导如下）：
- 已知：光速 c ≈ 3×10⁵ km/s（用3.2近似值便于口算），太阳光到地球时间 t = 8 min = 8×60 = 480 s。
- 距离 s = c × t = 3×10⁵ km/s × 480 s = 1.44×10⁸ km。
- **答案：太阳到地球距离约 1.44×10⁸ km（约1.5亿 km）。**
- 赛车时间：t = s / v = 1.44×10⁸ km ÷ 500 km/h = 2.88×10⁵ h。
  - 2.88×10⁵ h ÷ 24 = 1.2×10⁴ 天；1.2×10⁴ 天 ÷ 365 ≈ 32.9 年。
- **答案：赛车约需 2.88×10⁵ h ≈ 32.9 年（约33年）。**
- 判分关键：距离用 c×t，时间 min→s 换算正确；赛车用 距离÷速度，单位 km/h 一致。

**题5 光速比较**：透明介质中光速排序：空气 > 水中 > 玻璃（c > 3/4 c > 2/3 c）。猜想：气体 > 液体 > 固体（一般规律，需查资料检验）。判关系排序不判精确值。

#### 4.2 练习与应用（P97，5题）

**题1 反射角**：
- 已知光与镜面成30°角，则入射角 = 90° − 30° = 60°。
- **答案：反射角 = 60°。**
- 垂直入射：入射角 = 0°，反射角 = 0°，反射光沿原路（垂直镜面）射出。判「反射角=入射角=60°」与「垂直入射反射光原路返回」。

**题2 自行车尾灯**：判「尾灯内的角反射器使光经两次反射后沿与人射方向相反的平行方向反射」。作图为两道反射光线（见反射定律）。判光路两次反射反向。

**题3 太阳光竖直射入井中（平面镜定位）**：
- 太阳光与水平面成30°射向井口，需竖直向下入井。
- 入射光线方向与竖直向下方向夹角：从水平上方入，入射线与竖直向下方向成 90° − 30° = 60°。
- 平面镜将入射光转 60° 到竖直方向，转过的角 = 2×反射角变化 → 镜面与水平面夹角 =（90° − 30°）/2 + 30° = 60°。
- **答案：平面镜与水平面成60°角放置，反射角 = 30°。**
- ⚠️推导说明：入射光+竖直入井，入射线与竖直向下方向夹角60°；法线平分该60°角 → 入射角=反射角=30°；镜面与法线垂直 → 镜面与水平面夹角=60°。判作图位置+反射角30°。

**题4 积水明暗**：
- 迎着月光走：月光经水面镜面反射→反射光方向规则、反射光强，水面「亮」；路面漫反射→各方向弱，「暗」。
- 背着月光走：水面镜面反射的光沿反向规则射出，背离人眼方向 → 水面「暗」；路面漫反射仍有光入眼 →「相对亮」。
- 判「镜面反射vs漫反射」方向性差异表述。

**题5 激光测距**（含计算，推导）：
- 已知：激光往返时间 t = 2.56 s，光速 c = 3×10⁵ km/s。
- 单程时间 = t/2 = 1.28 s。
- 距离 s = c × (t/2) = 3×10⁵ km/s × 1.28 s = 3.84×10⁵ km。
- **答案：地球到月球距离约 3.84×10⁵ km（约38.4万 km）。**
- 判分关键：往返时间除以2取单程，再乘光速。

> 总方案（蔡总已拍板）：节=PhET式实验卡片页，一节一个整合实验为基本盘，多模式切换装下全部知识点，实验零题目零判分。

### 4.1 整合实验候选：光的直线传播（1 个整合实验，多模式切换）

**基本盘：一个「光的直线传播实验室」卡片页，内置 4 个模式（Tab/单选切换）：**

#### 模式 A：光在介质中沿直线传播（对应演示图4.1-2/4.1-3 + 介质定义）
- **知识点**：光在同种均匀介质中沿直线传播；介质（空气/水/玻璃）。
- **交互**：三介质切换（空气薄雾/盛水玻璃水槽加牛奶/玻璃砖），拖激光笔调整入射方向，实时显示直光路。
- **可调参数**：介质类型（下拉/切卡）、激光入射方向（拖拽）、是否显示径迹（牛奶/薄雾开关）。
- **2D/2.5D 分工**：直光路（绿色光线）锁死 2D；玻璃水槽/玻璃砖/激光笔 手画 2.5D 立体感。
- **PhET 借鉴映射**：借「光线模式」单选（出单条边缘光线）表现径迹；借「左下动画图标」触发一次脉冲光点从笔到介质传播。

#### 模式 B：小孔成像（对应想想做做图4.1-6/4.1-7）
- **知识点**：光的直线传播成倒立的像；物距变化影响像大小/清晰度。
- **交互**：烛焰（物）→小孔→薄膜（屏），可拖蜡烛改变物距、可拖薄膜改变屏距，倒立像随动。
- **可调参数**：物距（拖蜡烛）、孔大小、屏距（拖薄膜）。
- **2D/2.5D 分工**：烛焰到孔到屏的光路连线（多发光点经孔）锁死 2D；蜡烛/易拉罐（或圆筒）/薄膜 2.5D 立体。
- **PhET 借鉴映射**：借「光屏离焦模糊反馈」——膜前后拖拽时像从清晰→模糊（直接移植 PhET 光屏交互）；像=半透明倒立剪影。

#### 模式 C：光线模型 + 激光准直（对应图4.1-4/4.1-5 + 手影4.1-9）
- **知识点**：光线的表示（带箭头直线）；激光准直应用；手影/影子成因。
- **交互**：
  - 光线模型：选「光线」复选框，在光路上叠一条带箭头直线（光路图例开启）。
  - 激光准直：隧道场景，拖激光器使光束穿隧道引导掘进机直线前进。
  - 手影：台灯+手遮挡物，实时投出狗头状手影（遮挡物遮蔽形成暗区）。
- **可调参数**：箭头方向开关、遮挡物位置/形状。
- **2D/2.5D 分工**：光线符号/激光束/投影光路锁死 2D；隧道剖面/掘进机/台灯+手 2.5D 立体。
- **PhET 借鉴映射**：借「标注复选框」统一管光线箭头与图例；借「拖拽即物理」永远 live。

#### 模式 D：光速 + 科学世界（对应 P91 光速 + 科学世界图4.1-8）
- **知识点**：c = 299 792 458 m/s ≈ 3×10⁸ m/s = 3×10⁵ km/s；水/玻璃中光速 3/4 c、2/3 c；光年概念。
- **交互**：不是物理实验，为「数据/概念卡」模式——光速数值大卡、三介质光速对比条（c > 3/4 c > 2/3 c）、光年距离示意（牛郎星16光年/比邻星4.2光年）。
- **可调参数**：概念卡翻页、光速对比条高亮。
- **2D/2.5D 分工**：全部为 2D 卡片/对比条，无 2.5D 器材。
- **PhET 借鉴映射**：借「基础档给结论量」策略，光速直接给数值，不展开成因。

### 4.2 整合实验候选：光的反射（1 个整合实验，多模式切换）

**基本盘：一个「光的反射实验室」卡片页，内置 5 个模式：**

#### 模式 A：反射定律探究（对应实验图4.2-3/4.2-4/4.2-5 + 表格）
- **知识点**：法线/入射角 i/反射角 r；三线共面、两线分居、反射角=入射角；折纸板验证三线共面。
- **交互**：白色纸板 ENF 竖直立于平面镜，拖入射光线改变入射角，入射光 EO/反射光 OF 带箭头实时重绘，∠i、∠r 数值实时读数（反射角=入射角 live）。折纸板 NOF（交互点拖拽折起/放平）验证三线共面——折起纸板看不到反射光。
- **可调参数**：入射角（拖入射光线）、法线显隐、纸板 NOF 折起/放平、角度读数开关。
- **2D/2.5D 分工**：入射光线/反射光线/法线 ON 虚线/∠i∠r 弧线一律 2D 锁死在纸板平面；平面镜、纸板 ENF、激光笔 2.5D 立体（纸板可折起为立体动作）。
- **PhET 借鉴映射**：借「法线虚线+角度标注随拖拽实时读数」；借「光线模式边缘光线」清晰作图线；借「脉冲动画」演示光从激光笔→镜面→反射。

#### 模式 B：光路可逆（对应图4.2-6）
- **知识点**：反射现象中光路可逆。
- **交互**：切一个「光路可逆」开关或拖入射光逆着原反射光方向射入，观察反射光逆着原入射光方向射出，两条光线在镜面同点 V 形反向。
- **可调参数**：可逆开关、入射方向反转。
- **2D/2.5D 分工**：光线/法线/角度 2D；镜面 2.5D。
- **PhET 借鉴映射**：借「虚实像/方向自动判定零门槛」——光路可逆不需用户选模式，切开关即演示。

#### 模式 C：镜面反射 vs 漫反射（对应图4.2-7 + 想想议议）
- **知识点**：镜面反射/漫反射定义；粗糙度决定反射形态；光污染；黑板反光看不清字。
- **交互**：同一条平行入射光，切换「光滑/凹凸粗糙」表面，观察反射光从「平行规则」变「四面八方散射」。可加「黑板反光」场景：滑动粗糙度，黑板上的字清晰↔白亮模糊。
- **可调参数**：表面粗糙度（滑杆）、平行光束条数、入射方向。
- **2D/2.5D 分工**：平行入射/反射光线锁死 2D；镜面/纸张/黑板表面 2.5D（凹凸起伏立体纹理）。
- **PhET 借鉴映射**：借「滑杆三控一体」调粗糙度；借「多光线(光束感)」表现平行光/散射光。

#### 模式 D：角反射器 / 自行车尾灯（对应图4.2-8乙）
- **知识点**：两次反射后光沿与人射方向平行的反向射出（角反射器原理）。
- **交互**：角反射器（锯齿折面）任取一条入射光线，展示两次反射光路，最终反向射出；可联动尾灯示意图。
- **可调参数**：入射光线位置/角度、显示两次反射轨迹动画。
- **2D/2.5D 分工**：两次反射光路 2D；角反射器折面 2.5D。
- **PhET 借鉴映射**：借「标注复选框」开关法线与镜面标注。

#### 模式 E：反射应用（定日镜图4.2-1 + 井内竖直光4.2-9 + 看见物体4.2-2）
- **知识点**：反射定律解释定日镜；反射光入眼才能看见不发光的物体。
- **交互**：
  - 定日镜：太阳光角度可调，自动控制系统调整定日镜角度，反射光始终射向吸热塔顶。
  - 井：拖平面镜定位使太阳光竖直射入井中（轻量作图层，锁 30° 关系展示）。
  - 看见物体：书反射光入卡通学生眼睛，联动「看见不发光的物体」。
- **可调参数**：太阳方位（拖）、平面镜放置角度、光路显隐。
- **2D/2.5D 分工**：反射光路 2D；定日镜/吸热塔/井壁/书+学生 2.5D。
- **PhET 借鉴映射**：借「锁定图标」固定吸热塔靶点防误拖；借「底部控制面板」分区放太阳方位滑杆。
