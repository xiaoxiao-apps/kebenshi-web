## 一、课标要求（2022年版）

### 1.1 内容要求（二级主题 1.2 机械运动和物质，涉及物态变化）

> 1.2.2 经历物态变化的实验探究过程，知道物质的熔点、凝固点和沸点，了解物态变化过程中的吸热和放热现象。能运用物态变化的知识说明自然界和生活中的有关现象。

本节「温度」为物态变化单元的引入节，主要承担温度计使用、摄氏温度认识与实验测量技能的铺垫。

### 1.2 学业要求

- 能正确使用常见温度计测量温度（课标必做实验之一）。
- 知道摄氏温度的规定和单位，能正确读数。
- 能解释生活中与温度测量相关的简单问题。

### 1.3 教学提示

- 通过自制温度计等体验活动，理解液体温度计的工作原理。
- 重视温度计正确使用方法的操作规范训练。
- 借助体温计等实例，理解缩口结构的作用。
