体验环境：OpenClaw 浏览器，390×844 手机站视口，2026-09-14。
截图目录：`docs/competitor_shots/`。

## 工具1：长方体的认识（https://2026.anji.work/426/3dcfttj/）

### 布局结构
- 全屏画布型：整页即一块白色画布（2 个 canvas 叠放：绘制层 drawCanvas + 动画层）。
- 控件全部悬浮贴边：左侧竖排工具条（画笔✏️/橡皮🧼/4色圆点：红#FF3B30、黑#000、橙#FF9500、绿#34C759）；右上橙色「长方体」快捷按钮；右下蓝色「开始/继续/重置」主按钮组。
- 无标题栏、无说明文字区，界面极简，靠动画内的竖排文字（「线动成面」）做教学提示。

### 颜色搭配
- 背景：近白浅灰 #F5F7FA 系（body 透明，页面底色浅灰白）。
- 主按钮（开始/继续）：iOS 蓝 rgb(0,122,255) = #007AFF。
- 快捷按钮「长方体」：橙 #FF9500。
- 次按钮/工具条底：浅灰 rgb(230,235,241) = #E6EBF1，圆形白底图标钮。
- 动画线条：亮蓝 #007AFF 系细线。
- 整体=iOS 系统色板（蓝+橙+灰白），干净但无品牌个性。

### 交互设计
- 主流程单按钮推进：开始→继续→…分步播放「点动成线→线动成面→面动成体」，按钮文字随状态切换（开始/继续），反馈明确。
- 附加涂鸦层：画笔/橡皮/4 色可在画布上自由标注，服务课堂讲解。
- 输入框 lR/wR/hR（长宽高）存在但首屏不可见，疑为后续步骤或隐藏面板。
- 反馈形式：动画本身即反馈，无 toast/弹窗打扰。

### 丝滑度判断
- 动画实现：requestAnimationFrame ×1（内联 script），无 setInterval/CSS transition/animation 命中 → 纯 rAF 逐帧绘制 canvas。
- 实测点击「开始」后线条匀速绘制、竖排文字同步浮现，无跳帧感；截图时动画进行中状态完整。
- 卡顿线索：无明显布局抖动；双 canvas 分层（静态涂鸦/动态动画）避免整幅重绘，是丝滑的关键设计。

### 亮点
1. 双 canvas 分层：涂鸦层与动画层分离，标注重绘不干扰主动画。
2. 单主按钮状态机（开始/继续/重置）推进教学步骤，认知负担极低。
3. 动画内嵌竖排结论文字（线动成面），演示与结论同屏。

### 不足
1. 首屏空白过大，无标题/目标说明，初次打开不知用途。
2. 长宽高输入框隐藏，功能发现性差。
3. 配色直接用系统色，缺教材品牌感；工具条悬浮位置偏怪（左中）。

## 工具2：面动成体（https://2026.anji.work/pc/ke/13/）

### 布局结构
- 三段式竖屏：顶部引导卡片（「嗨，小探险家！」3步操作说明，白底蓝边圆角卡）→ 中部主画布（方格纸背景+红色虚线旋转轴+可拖拽图形）→ 底部固定工具托盘（「图形百宝箱」6形状按钮 + 「属性与工具」轴切换）。
- 右上悬浮 +/- 缩放圆钮；3D 模式下顶部卡片切换为「组合变身！」解说文案。
- 信息分层清晰：说明、操作区、工具区互不遮挡，手机站单手可及底部托盘。

### 颜色搭配
- 画布区：浅蓝灰方格纸 #EAF0F8 系，网格线更浅；旋转轴红虚线 #E05A5A。
- 底部托盘：淡紫蓝 #C9D6F2 圆角面板，内嵌白色半透明卡 rgba(255,255,255,0.85)。
- 形状色板（高饱和糖果色）：蓝 #3D7EF7、绿 #4CD97B、橙 #F2703B、红 #E8443A、黄 #F7D038、紫 #B44CF0。
- 引导卡：白底 + 天蓝描边 #4AA8E8 + 蓝色标题字；3D 旋转体用蓝色渐变线框 #6FA8F5→#3D7EF7。
- 整体=「卡通课件风」：浅蓝底+糖果色形状+白卡，儿童友好度高于工具1。

### 交互设计
- 主控件：形状按钮添加→拖拽移动/变形/拼接→「✨3D变身！」播放旋转→rotation-slider（0-360°）手动 scrub 旋转角→「返回修改」回编辑态。状态机完整（编辑/3D 双态，按钮显隐切换）。
- 轴切换：竖直/水平旋转轴 pill 二选一，active 态蓝底白字。
- 反馈：3D 态顶部文案实时讲解（「跨轴的图形像钢坯切开空间…」），slider 拖动即时重绘线框，所见即所得。
- 缩放 +/-、删除/清空小按钮齐备，容错好。

### 丝滑度判断
- 动画实现：requestAnimationFrame×1 + CSS animation×7（UI 弹跳/卡片动效），无 setInterval → 3D 线框逐帧 canvas 重绘，UI 微动效走 CSS。
- 实测：点击 3D 变身后线框扫掠成型流畅；slider 设 180° 立即重绘半周轨迹，无延迟感。
- 卡顿线索：无；单 canvas 但 3D 态无涂鸦层负担，线框密度适中。

### 亮点
1. 编辑态/3D 态双状态机 + slider scrub，把「面动成体」变成可手动回放的过程。
2. 引导卡文案口语化、分步编号，进入 3D 态自动换讲解文案（情境化反馈）。
3. 方格纸背景+糖果色形状，视觉即「数学课本」，品牌感强于工具1。

### 不足
1. 底部托盘占屏约 28%，小屏上画布被压缩。
2. 形状按钮无文字标签，仅靠图标猜含义。
3. 3D 线框无明暗/消隐，背面线条透过来略乱。

## 工具3：鸡兔同笼（https://2026.anji.work/pc/sixia/jttl.html）

### 布局结构
- 经典 App 式竖排：蓝色渐变顶栏（emoji 标题🐔🐰鸡兔同笼 + 3 个方法 tab：列表尝试法/假设法/古人抬脚法）→ 题目卡（薄荷绿底，关键数字橙色高亮）→ 列表表格卡（鸡/兔/总脚数 三行网格）→ 控制卡（鸡/兔双 slider + 实时算式条 🐔×2+🐰×4=?）。
- 卡片流单列布局，圆角白卡+大间距，手机站阅读舒适；三种解法用 tab 切换复用同屏结构。

### 颜色搭配
- 页面底：灰蓝 rgb(211,224,233) = #D3E0E9。
- 顶栏：蓝渐变（#5B9BD5→#7FB3E0 系）白字；active tab 白底蓝字，未选透明描边。
- 题目/算式卡：薄荷绿 rgb(216,251,247) = #D8FBF7；关键数字橙红 #F2703B。
- 表格：白底+蓝边 #2E75B6，表头列薄荷绿；记录按钮浅绿 rgb(167,219,167) = #A7DBA7。
- slider 滑块：实心蓝圆 #1F7AC9。整体=「蓝+薄荷绿+橙点缀」，清爽学科风。

### 交互设计
- 双 slider 联动约束（鸡+兔=8 自动互补），拖鸡 slider 兔自动变，表格列实时填入 4/4/24，算式条同步——输入即反馈，零等待。
- 「📝记录」把当前尝试写入表格列，支持列表尝试法的枚举过程留痕。
- 假设法/抬脚法为分步按钮流（▶️下一步 / 👇抬起一半脚），逐步演示解题动作。
- 反馈全内联（表格+算式变色），无弹窗。

### 丝滑度判断
- 动画实现：rAF/setInterval/transition/animation 全 0 命中 → 纯 DOM 直更，无动画层。
- 实测：slider 拖动表格数字即时更新，因无动画反而「跟手」；但步骤切换无过渡，画面硬切。
- 卡顿线索：无卡顿，也无动效缓冲，质感偏「表单」而非「课件」。

### 亮点
1. 约束联动 slider（和恒为8）把枚举空间物理化，拖一下=一次尝试，教学隐喻准确。
2. 题目数字橙色高亮+emoji 算式条，读题与建模同屏。
3. 三解法 tab 化，一工具覆盖教学全流程。

### 不足
1. 零动画零过渡，步骤演示靠硬切，丝滑度四工具中最弱。
2. 记录按钮反馈不明显（点击后无 toast/高亮），留痕感知弱。
3. 顶栏渐变与卡片色系略脱节（蓝顶栏 vs 薄荷卡），统一感逊于工具2。

## 工具4：长方体盒子展开（https://2026.anji.work/pc/sanshang/cft/index.html）

### 布局结构
- 极简三段：顶部标题行（黑字标题+右上蓝色⚙️设置圆钮）→ 白底提示条「点击棱边把它'剪开'，观察面是如何展开的！」→ 全屏 3D 场景（Three.js 单 canvas）。
- 右下红色🔄重置浮动圆钮；设置面板内含 宽/高/深 三 slider 与「收拢/展开」按钮（默认收起，首屏只见主场景）。
- 3D 盒体六面贴汉字标签（上/前/右…），棱边用黄色高亮条标出可点击的「剪刀棱」。

### 颜色搭配
- 页面底：爱丽丝蓝 rgb(240,248,255) = #F0F8FF。
- 盒体六面糖果色：顶橙 #E67E22、前绿 #2ECC71、右蓝 #3498DB（+黄棱 #F1C40F 高亮）。
- 浮动钮：重置红 rgb(255,107,107) = #FF6B6B、设置蓝 rgb(75,123,236) = #4B7BEC、折叠绿 rgb(46,204,113) = #2ECC71。
- 整体=Flat UI 经典色板（Flat UI colors），面色区分度极高，利于「认面」。

### 交互设计
- 核心隐喻：点棱=剪开。点击黄色棱边逐条剪开并翻折展开，配合「收拢」按钮可逆回放。
- 设置面板暴露长宽高 slider，改尺寸实时重建盒子（参数化教具）。
- 反馈：3D 翻折动画本身；提示条常驻说明操作方式（比工具1的首屏空白友好）。
- 注意：合成 pointer 事件点 canvas 未触发剪棱（疑需真实 hit-test 坐标或 drag），真实手指体验应优于脚本模拟。

### 丝滑度判断
- 动画实现：Three.js（script 内命中 THREE）+ requestAnimationFrame×1 渲染循环；无 CSS transition/animation、无 setInterval。
- 实测：首屏 3D 盒子渲染即时、无白屏；点击「收拢」（已收拢态）无多余动作，状态判断正确。
- 卡顿线索：手机站视口下 WebGL 单场景负载低，未见掉帧迹象；展开翻折为逐帧插值，预期平滑。

### 亮点
1. 「点棱剪开」把展开图生成变成探索游戏，因果反馈直接（剪哪条棱翻哪个面）。
2. 六面汉字标签+高饱和面色，展开后仍能追踪面对应关系，教学信息不丢。
3. 参数 slider 藏进⚙️面板：首屏极简、进阶可调，收纳策略值得学。

### 不足
1. 首屏盒子偏小、四周留白过大，手机站空间利用不足。
2. 可点击棱仅靠黄色条暗示，无新手引导箭头/脉冲提示，发现性一般。
3. 重置/设置/收拢三钮分散（右下/右上/面板内），操作动线不统一。

## 总体结论

### 四个工具的共同设计语言
1. **手机站优先的单列/全屏画布布局**：无侧栏无菜单，控件悬浮贴边或底部托盘，单手可达。
2. **卡片化+大圆角**：白卡/薄荷卡圆角 12-16px，浅灰蓝或浅蓝底衬托，内容块边界清晰。
3. **高饱和糖果色做教学语义色**：形状/面/关键数字一律高饱和（蓝#3D7EF7、绿#2ECC71、橙#E67E22、红#FF6B6B），与低饱和底色形成强对比。
4. **单主按钮状态机推进教学步骤**（开始/继续/下一步/3D变身），按钮文字即进度提示。
5. **动画=反馈**：核心结论靠 canvas/WebGL 逐帧动画呈现（3/4 工具用 rAF），UI 微动效走 CSS animation；无一家用弹窗说教。
6. **emoji 当图标**：🐔🐰✏️⚙️ 零图标成本、儿童亲和，但风格统一性靠配色兜底。

### 值得借鉴到 c1s2（运动的描述）的点
- **UI**：① 顶部「标题+一句话操作提示条」常驻（工具4），比工具1的空白首屏好；② 进阶参数收进⚙️折叠面板，首屏只留主场景+主按钮；③ 底部固定托盘放控件，拇指区操作。
- **配色**：① 语义色高饱和、背景低饱和的对比公式（底色 #F0F8FF 系 + 物体色糖果色）；② 关键数字/关键词用橙红高亮嵌在题干句内（工具3）；③ 运动物体（汽车/参照物）各配一糖果色并全程不变，帮学生追踪对象。
- **交互**：① 单主按钮状态机播「参照物选择→运动判断」分步动画，按钮文字随态切换；② slider scrub 回放过程（工具2 的旋转角 slider 思路→c1s2 可做时间轴 slider 拖拽回看任意时刻位置）；③ 点击物体本身切换参照物（工具4「点棱剪开」的直接操纵隐喻），优于下拉框选择。

### 要避的坑
1. **零动画硬切**（工具3）：步骤切换无过渡会显廉价；c1s2 至少给状态切换加 200-300ms 过渡。
2. **首屏无说明**（工具1）：打开不知干什么；提示条成本极低必须有。
3. **可点击元素发现性差**（工具4 黄棱、工具1 隐藏输入框）：可交互对象要有脉冲/描边/文案三选一指引。
4. **控件动线分散**（工具4 三钮三处）：主操作集中一处，浮动钮≤2 个。
5. **系统色裸用**（工具1 #007AFF）：无品牌感；咱们已有棕绿教材色系，应延续而非抄竞品蓝。

### 与咱们 c1s1 现风格对比（common.css :root）
- 咱们：暖纸感米白底 #faf8f5 + 白卡 + 棕金 #8b6914/#c4a35a 主色 + 绿 #4a8c3f / 红 #c0392b / 青 #2980b9 语义色，圆角 14px，阴影柔和 → 「纸质教材数字化」气质。
- 竞品：冷底（#F0F8FF/#D3E0E9/#EAF0F8）+ 糖果色 + 更重圆角/描边卡片 → 「卡通 App」气质。
- 结论：**不抄竞品色板**（暖纸感是咱们差异化），但借其三条公式：①语义色饱和度上调一档（c1s2 运动物体可用 --cyan/--green 提亮版）；②题干关键词内嵌高亮（用现成 --red/--gold）；③单主按钮状态机+时间轴 slider 的交互骨架。圆角/卡片/阴影维持 c1s1 变量不动，保证两节视觉连续。

（完）
