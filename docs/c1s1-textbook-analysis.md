## 二、网页端盘点

目录 `content/physics_g8_v1_c1_s1/`，11个文件（只读盘点）：

### 页面结构（6页）
| 文件 | 角色 |
|---|---|
| index.html | 导航页：5卡片入口（导入/讲解/实验/练习/小结） |
| anim.html | 导入小剧场：36s canvas 动画5幕（小明目测锯书架翻车→测量三要素→时间也重要→点题），播放/暂停/重播，全屏支持 |
| explain.html | 知识讲解（静态）：①长度单位（7单位胶囊+进率口诀+4参照物）②刻度尺五步"认放看读记"（含非0起点、视差、估读示例、易错框2.35cm）③停表双盘读数（小盘0.5min/大盘30s×0.1s、半分钟进位陷阱示例1min37.5s） |
| experiment.html | 互动实验区（2个canvas交互） |
| quiz.html | 小练习：3道单选（估读位数/刻度尺使用/停表进位），答完显示得分 |
| summary.html | 小结：3分支知识导图+两大易错点警示框 |

### 交互模块（4个）
1. **刻度尺读数练习**（experiment.js）：随机生成起点(1.0~5.0cm整0.1)与长度(1.50~4.30cm整0.01)的铅笔，8cm尺/1mm分度；用户输入读数(cm或mm)→判分（±0.02cm容差）→显示"末端−起始"算式讲解→换一题。覆盖：量程/分度值、非0起点、估读到下一位。
2. **停表读数练习**（experiment.js）：canvas画双盘停表（大盘0-60刻度、小盘0-3分钟）；"出题"随机目标(1~2min, 0~59.9s)，2秒未操作自动走针到目标；用户填分/秒→判分（分±0.5、秒±0.15容差）→错误时讲解过中线加30s。另有开始/停止/归零真实计时。覆盖：停表读数+半分钟进位。
3. **导入动画**（anim.js）：见上，纯叙事无交互判断。
4. **三题单选测验**（quiz.html内联JS）：即时判分+讲解+总分。

### 支撑文件
- common.css：全站米色/绿棕主题样式；fullscreen.js：全屏API+伪全屏降级；anim.html/experiment.html 均绑定。
- **app.js（26KB）疑为旧版遗留**：含暗色主题的全部三模块（动画+实验+测验），当前无任何 html 引用它（各页分别引 anim.js/experiment.js/内联JS）。属死代码。
